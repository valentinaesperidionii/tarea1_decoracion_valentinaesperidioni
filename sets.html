SETS QUE DECORAN EN CONJUNTO

Los sets combinan distintos elementos decorativos, pensados para armar un rincon completo de una sola vez.

Cada uno tiene su propia impronta, asi que vas a encontrar desde combinaciones minimalistas hasta otras mas calidas, ideales para living, mesa de luz o cualquier rincon que quieras renovar

Set esencial

Incluye: difusor de varillas, vela y bandeja.

Difusor de varillas en frasco de vidrio con tapa de madera, acompañado de una vela redondeada tipo piedra, todo sobre una bandeja blanca, la combinacion basica para empezar a decorar con aroma.

Set luz

Incluye: florero acanalado, flor de tela, vela y bandeja ovalada.

Florero blanco acanalado con flores de tela y borla, junto a una vela con forma de manzana, dispuestos en una bandeja ovalada, un set con formas organicas y mucha calidez.

Set delhi

Incluye: porta sahumerios, sahumerios, vela en cuenco de ceramica y caja de regalo.

Presentado en caja de regalo, incluye un porta sahumerios con forma de mano de Fatima, varillas de incienso y una vela en cuenco de ceramica. Perfecto para regalar o darse un gusto.

Set athenas

Incluye: florero circular, flores secas, portavela de vidrio, vela y bandeja de madera.

Combina un florero circular en blanco con flores secas y un portavela de vidrio con vela, todo apoyado sobre una bandeja de madera, un set simple y elegante para sumar textura natural.
